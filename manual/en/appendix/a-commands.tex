\chapter{Command reference}
\markboth{Appendix A · Command reference}{Appendix A · Command reference}

The tables below list the main commands of each workbench: the English label, the label the Chinese interface
shows, and the FreeCAD command ID. The ID is the same as on the desktop: search it there, or run
\file{Gui.runCommand("ID")} in FreeCAD's Python console. The in-app \ui{Search all tools} box searches all 984
commands; its data is \file{assets/freecad/catalog.json} in this repository.
