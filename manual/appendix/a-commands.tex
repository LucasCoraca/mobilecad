\chapter{常用命令速查}
\markboth{附录 A 常用命令速查}{附录 A 常用命令速查}

下表按工作台列出主要命令（中文、英文、命令 ID），优先收工具条上可见的命令。命令 ID 与 FreeCAD 桌面
完全一致：在桌面版里搜索同一个 ID，或在 Python 控制台执行 \file{Gui.runCommand("ID")}，效果相同。
应用内工具面板的\ui{搜索所有工具}可检索全部 984 条命令，数据源为仓库中的 \file{assets/freecad/catalog.json}。
